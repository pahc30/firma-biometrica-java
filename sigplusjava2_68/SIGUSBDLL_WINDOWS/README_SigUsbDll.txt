The SigUsb.dll files require both the VC++ 2008 and 2010 runtimes to function properly. The runtimes are available in 32-bit and 64-bit versions. Use the appropriate version for your JVM. Please download and install the VC++ runtimes before using your pad.

Bear in mind that the paths to these installers will certainly change over time. Ultimately, you can visit www.microsoft.com to locate the current 32-bit and 64-bit 2008 and 2010 VC++ redistributables available to you.



VC++ 32-bit versions (for 32-bit JVM):
2008 VC++ 32-bit redistributable:
